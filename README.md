# Familiar

Тренажёр узнавания лиц для macOS, написанный на Rust.

Перед тобой быстро идут лица. Если человек уже появлялся в этой серии, даже в другом облике (очки, борода, причёска, грим, ракурс), нужно сразу нажать кнопку. Ошибка или пропуск наказываются вспышкой и звуком. Скорость показа растёт, пока справляешься.

## Структура

| Путь | Что это |
|---|---|
| `crates/familiar-core` | Логика тренировки без UI: серии, повторы, адаптивная скорость, уровни маскировки, подсчёт точности, история. Позже переиспользуется на iOS. |
| `crates/familiar-mac` | Приложение для macOS. |
| `scripts/prepare_celeba.py` | Скачивает CelebA (лимит 3 ГБ) и готовит выборку лиц по папкам. |

## Данные

Лица хранятся вне репозитория, в `~/Documents/Familiar/faces`:

```
faces/
  manifest.json        признаки каждого фото (очки, борода, цвет волос...)
  <id человека>/
    000123.jpg
    ...
```

Подготовка:

```sh
python3 scripts/prepare_celeba.py --out ~/Documents/Familiar
```

CelebA разрешено использовать только в некоммерческих исследовательских целях, распространять набор нельзя. Поэтому фото и история тренировок исключены из git в `.gitignore`.

## Сборка

Нужны [rustup](https://rustup.rs) и Xcode Command Line Tools (`xcode-select --install`).

```sh
cargo build --release
cargo test --workspace
```

Сборка `Familiar.app` для папки Applications:

```sh
cargo install cargo-bundle
cargo bundle --release -p familiar-mac
```

Приложение не подписано сертификатом Apple. При первом запуске нажми на него правой кнопкой и выбери «Открыть».
